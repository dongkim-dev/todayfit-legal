CellTimer

단식·오토파지 과학 콘텐츠 자동 제작 도구 · 1인 개발자 운영

CellTimer는 단식과 오토파지에 관한 과학 기반 짧은 영상을 제작하여 운영자 본인이 소유한 YouTube 채널에 업로드하는 개인용 자동화 도구입니다. 운영자의 로컬 컴퓨터에서만 실행되며, 일반 이용자에게 배포되거나 제공되는 서비스가 아닙니다.

주요 기능

  • 단식·오토파지 관련 주제 선정 및 대본 생성
  • 음성 합성과 영상 렌더링을 통한 짧은 영상 제작
  • YouTube Data API를 통한 운영자 본인 채널 업로드
  • 업로드한 영상에 안내 댓글 작성

Google 계정 사용 범위

CellTimer는 운영자 본인의 Google 계정 하나에만 연결됩니다. 사용하는 권한은 영상 업로드(youtube.upload)와 업로드한 영상의 댓글 작성(youtube.force-ssl)뿐이며, 다른 이용자의 계정이나 데이터에는 접근하지 않습니다.

고지

CellTimer가 제작하는 영상은 교육 목적의 정보이며 의학적 조언이 아닙니다. 장기 단식을 시도하기 전에는 반드시 의료 전문가와 상담하시기 바랍니다.
